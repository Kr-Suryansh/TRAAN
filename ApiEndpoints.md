# TRAAN API Endpoints

This document outlines the active, verified API endpoints for the TRAAN unified backend (Component D+E).

## Base URL
- Development: `http://localhost:8000/api/v1`
- Network: `http://<backend-ip>:8000/api/v1`

## SOS & Ingestion (Mobile App)
These endpoints are used by Component C (Gateway Node) to upload offline mesh payloads.
- `POST /sos/batch`: Uploads a batch of SOS requests collected from the mesh. Processes deduplication, spatial clustering, and triggers the AI pipeline for incident creation.
- `GET /sos/{uuid}/status`: Checks the current status of an SOS (e.g. pending, uploaded, processed).

## Incidents (Dashboard)
These endpoints manage the clustered incidents generated by the AI pipeline.
- `GET /incidents`: Retrieves a paginated list of all active incidents. Supports filtering.
- `GET /incidents/{incident_id}`: Retrieves detailed information about a specific incident, including the AI summary and SOS list.
- `PATCH /incidents/{incident_id}`: Updates incident properties (e.g., status, severity).
- `GET /incidents/{incident_id}/recommendations`: Retrieves AI/OR-Tools generated resource recommendations for the incident.
- `POST /incidents/{incident_id}/dispatch`: Dispatches assigned resources to the incident.
- `POST /incidents/{incident_id}/refresh-summary`: Forces the Gemini AI to re-evaluate the incident's summary based on new SOS reports.

## Resources
Manages rescue and relief resources available to the authorities.
- `GET /resources`: Retrieves all available resources (ambulances, helicopters, SDRF units).
- `POST /resources`: Creates a new resource.
- `GET /resources/{resource_id}`: Retrieves specific resource details.
- `PATCH /resources/{resource_id}`: Updates resource properties.

## Optimizer & AI
Direct access to the OR-Tools optimizer and Gemini Situation Briefing.
- `GET /optimizer/situation-brief`: Retrieves the overarching AI-generated situation brief for the entire disaster zone.
- `POST /optimizer/situation-brief/refresh`: Forces a regeneration of the situation brief.
- `POST /optimizer/optimize/allocate`: Triggers a manual OR-Tools allocation run for resources.

## Dashboard Statistics
- `GET /stats/summary`: Returns high-level metrics (total incidents, active SOS, resources deployed) for the dashboard overview.
- `GET /stats/activity-timeline`: Returns a timeline of system activity.

## Authentication
- `POST /auth/device/register`: Registers a mobile device.
- `POST /auth/authority/login`: Dashboard login for authorities (returns JWT).
- `POST /auth/authority/refresh`: Refreshes the JWT.
